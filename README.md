# PenaltyIQ

PenaltyIQ estimates the outcome of a penalty kick when a striker faces a goalkeeper. For any kicker and goalkeeper pairing, it returns the probability of each of three outcomes: Goal, Stopped by the GK, or Missed.

Installation steps:

1. Run the notebook 'synthetic_data_creation'. This will create the db file 'epl_synthetic_penalties' inside the 'output_data' folder.

2. Make sure the 'index.html' file is inside the 'template' folder.

3. Run the 'app.py' file

4. Open http://127.0.0.1:5000 in your browser

5. Have fun!
